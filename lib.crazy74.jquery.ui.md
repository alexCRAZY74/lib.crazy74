# Библиотека lib.crazy74.jquery.ui.js

Набор jQuery-плагинов для позиционирования элементов, создания модальных окон и контекстных меню.

---

## 1. Позиционирование: `$.fn.csl74Position`

Мульти-объектное позиционирование элементов с контролем коллизий относительно других элементов или окна браузера.

### Сигнатура
```javascript
$(element).csl74Position(rules, globalOptions);
```

### Параметры

* **`rules`** (Array|Object): Одно правило или массив правил позиционирования. Каждое правило может содержать:
  * `of` (Selector|jQuery|Element): Целевой элемент, относительно которого позиционируем.
  * `my` (String): Точка привязки текущего элемента (например, `'left top'`, `'right-10 bottom+5'`).
  * `at` (String): Точка привязки целевого элемента (например, `'left bottom'`).
  * `axis` (String): Ограничение по оси (`'x'` или `'y'`).
  * `offset` (Array|Object): Дополнительное смещение. Массив `[x, y]` или объект `{x: 10, y: 20}`.
* **`globalOptions`** (Object): Глобальные настройки:
  * `collision` (String): Режим обработки коллизий:
    * `'none'` — без обработки.
    * `'fit'` — вписать в границы.
    * `'flip'` — зеркально отразить относительно целевой точки.
    * `'flipfit'` — сначала отразить, если не влезает — вписать (по умолчанию).
  * `within` (Window|Selector|jQuery|Element): Границы, в пределах которых контролируются коллизии (по умолчанию `window`).

## 2. Модальные окна: `$.csl74Window` / `$.fn.csl74Window`

Компонент для создания и управления модальными окнами. Может вызываться как статический метод или как плагин на существующем элементе.

### Сигнатура
```javascript
// Статический вызов (создание нового окна из параметров)
const win = $.csl74Window(options);

// Вызов на элементе (содержимое элемента переносится в окно)
const win = $(selector).csl74Window(options);
```

### Настройки по умолчанию (`defaults`)
```javascript
{
  icon: false,             // Класс иконки (string) для заголовка
  title: 'Окно',           // Текст заголовка
  content: '',             // Контент (строка, HTML или jQuery-объект)
  customClass: '',         // Кастомный CSS-класс для стилизации
  contentStyle: '',        // Дополнительный класс для контейнера контента
  withBackDrop: true,      // Отображать затемнение заднего фона
  destroyOnClose: true,    // Удалять элементы из DOM при закрытии
  closeOnEsc: true,        // Закрывать по нажатию Escape
  duration: 150,           // Длительность анимации (ms)
  width: null,             // Ширина ('500px', 500 или null)
  height: null,            // Высота контента ('400px', 400 или null)
  labels: {
    close: 'Закрыть',
    title: 'Информационное окно'
  },
  'z-group': 'body > *, .csl-window-frame, .csl-window-backdrop, .-webkit-scrollbar',
  onClose: null            // Колбек при закрытии окна
}
```

### Возвращаемый интерфейс управления
Метод возвращает объект со следующими методами и свойствами:
* `$frame`: jQuery-объект фрейма окна.
* `$content`: jQuery-объект контейнера содержимого.
* `close()`: Функция закрытия окна.
* `setTitle(newTitle)`: Метод динамического изменения заголовка.
* `setContent(newContent)`: Метод динамического изменения содержимого.

## 3. Контекстные меню: `$.fn.csl74Menu` / `$.csl74Menu`

Плагин для создания выпадающих или контекстных меню, привязанных к триггеру.

### Сигнатура
```javascript
$(trigger).csl74Menu(options);
```

### Настройки (`options`)
* `items` (Array|Function): Массив элементов меню или функция, возвращающая массив (или Promise, разрешающийся в массив).
* `position` (Array): Конфигурация позиционирования меню относительно триггера. По умолчанию:
  ```javascript
  [
    [{ my: 'left top', at: 'left bottom' }],
    { collision: 'flipfit' }
  ]
  ```
* `maxlen` (Number): Максимальная длина текста пункта меню (длинный текст обрезается с добавлением `title`). По умолчанию `50`.
* `renderItem` (Function): Кастомная функция отрисовки пункта меню.
* `onSelect` (Function): Колбек при выборе пункта: `function(value, item, $trigger, event)`.
* `onOpen` (Function): Колбек при открытии меню: `function($menu, $trigger)`.
* `onClose` (Function): Колбек при закрытии меню: `function($trigger)`.

### Формат элементов (`items`)
Элементы массива `items` могут быть:
1. Строкой `'-'` — разделитель меню.
2. Простой строкой — преобразуется в пункт меню, где значение и лейбл совпадают.
3. Объектом конфигурации пункта:
   ```javascript
   {
     value: 'edit',          // Значение пункта
     label: 'Редактировать', // Отображаемый текст (опционально)
     icon: 'icon-edit',      // Класс иконки (опционально)
     disabled: false,        // Флаг отключения пункта (опционально)
     danger: false,          // Флаг опасного действия (подсветка красным)
     onClick: function(item, $trigger, event) { ... }, // Индивидуальный обработчик клика
     render: function(item, opts, $trigger) { ... }    // Индивидуальный рендерер пункта
   }
   ```

### Статические методы
* `$.csl74Menu.close()`: Принудительное закрытие активного меню.
