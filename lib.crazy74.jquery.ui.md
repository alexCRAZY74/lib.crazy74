# Библиотека lib.crazy74.jquery.ui.js

Набор jQuery-плагинов для позиционирования элементов, создания модальных окон и контекстных меню.

---

## 1. Позиционирование: `$.fn.csl74Position`

Мульти-объектное позиционирование элементов с контролем коллизий относительно других элементов или окна браузера.

### Сигнатура
```javascript
$(element).csl74Position(rules, globalOptions);
```

### Параметры

* **`rules`** (Array|Object): Одно правило или массив правил позиционирования. Каждое правило может содержать:
  * `of` (Selector|jQuery|Element): Целевой элемент, относительно которого позиционируем.
  * `my` (String): Точка привязки текущего элемента (например, `'left top'`, `'right-10 bottom+5'`).
  * `at` (String): Точка привязки целевого элемента (например, `'left bottom'`).
  * `axis` (String): Ограничение по оси (`'x'` или `'y'`).
  * `offset` (Array|Object): Дополнительное смещение. Массив `[x, y]` или объект `{x: 10, y: 20}`.
* **`globalOptions`** (Object): Глобальные настройки:
  * `collision` (String): Режим обработки коллизий:
    * `'none'` — без обработки.
    * `'fit'` — вписать в границы.
    * `'flip'` — зеркально отразить относительно целевой точки.
    * `'flipfit'` — сначала отразить, если не влезает — вписать (по умолчанию).
  * `within` (Window|Selector|jQuery|Element): Границы, в пределах которых контролируются коллизии (по умолчанию `window`).

## 2. Модальные окна: `$.csl74Window` / `$.fn.csl74Window`

Компонент для создания и управления модальными окнами. Может вызываться как статический метод или как плагин на существующем элементе.

### Сигнатура
```javascript
// Статический вызов (создание нового окна из параметров)
const win = $.csl74Window(options);

// Вызов на элементе (содержимое элемента переносится в окно)
const win = $(selector).csl74Window(options);
```

### Настройки по умолчанию (`defaults`)
```javascript
{
  icon: false,             // Класс иконки (string) для заголовка
  title: 'Окно',           // Текст заголовка
  content: '',             // Контент (строка, HTML или jQuery-объект)
  customClass: '',         // Кастомный CSS-класс для стилизации
  contentStyle: '',        // Дополнительный класс для контейнера контента
  withBackDrop: true,      // Отображать затемнение заднего фона
  destroyOnClose: true,    // Удалять элементы из DOM при закрытии
  closeOnEsc: true,        // Закрывать по нажатию Escape
  duration: 150,           // Длительность анимации (ms)
  width: null,             // Ширина ('500px', 500 или null)
  height: null,            // Высота контента ('400px', 400 или null)
  labels: {
    close: 'Закрыть',
    title: 'Информационное окно'
  },
  'z-group': 'body > *, .csl-window-frame, .csl-window-backdrop, .-webkit-scrollbar',
  onClose: null            // Колбек при закрытии окна
}
```

### Возвращаемый интерфейс управления
Метод возвращает объект со следующими методами и свойствами:
* `$frame`: jQuery-объект фрейма окна.
* `$content`: jQuery-объект контейнера содержимого.
* `close()`: Функция закрытия окна.
* `realign()`: Метод перепозиционирования окна.
* `setTitle(newTitle)`: Метод динамического изменения заголовка.
* `setContent(newContent)`: Метод динамического изменения содержимого.

## 3. Контекстные меню: `$.fn.csl74Menu` / `$.csl74Menu`

Плагин для создания выпадающих или контекстных меню, привязанных к триггеру.

### Сигнатура
```javascript
$(trigger).csl74Menu(options);
```

### Настройки (`options`)
* `items` (Array|Function): Массив элементов меню или функция, возвращающая массив (или Promise, разрешающийся в массив).
* `position` (Array): Конфигурация позиционирования меню относительно триггера. По умолчанию:
  ```javascript
  [
    [{ my: 'left top', at: 'left bottom' }],
    { collision: 'flipfit' }
  ]
  ```
* `maxlen` (Number): Максимальная длина текста пункта меню (длинный текст обрезается с добавлением `title`). По умолчанию `50`.
* `renderItem` (Function): Кастомная функция отрисовки пункта меню.
* `onSelect` (Function): Колбек при выборе пункта: `function(value, item, $trigger, event)`.
* `onOpen` (Function): Колбек при открытии меню: `function($menu, $trigger)`.
* `onClose` (Function): Колбек при закрытии меню: `function($trigger)`.

### Формат элементов (`items`)
Элементы массива `items` могут быть:
1. Строкой `'-'` — разделитель меню.
2. Простой строкой — преобразуется в пункт меню, где значение и лейбл совпадают.
3. Объектом конфигурации пункта:
   ```javascript
   {
     value: 'edit',          // Значение пункта
     label: 'Редактировать', // Отображаемый текст (опционально)
     icon: 'icon-edit',      // Класс иконки (опционально)
     disabled: false,        // Флаг отключения пункта (опционально)
     danger: false,          // Флаг опасного действия (подсветка красным)
     onClick: function(item, $trigger, event) { ... }, // Индивидуальный обработчик клика
     render: function(item, opts, $trigger) { ... }    // Индивидуальный рендерер пункта
   }
   ```

### Статические методы
* `$.csl74Menu.close()`: Принудительное закрытие активного меню.

## 4. Выпадающие списки: `$.fn.csl74Select`

Плагин для стилизации стандартных HTML-элементов `<select>` с использованием контекстного меню `csl74Menu`.

### Сигнатура
```javascript
$(selector).csl74Select(options);
```

### Описание работы
* Оборачивает нативный `<select>` в контейнер `.csl74-select` (если он ещё не обёрнут).
* Достраивает структуру DOM: добавляет элемент `.csl74-select-value` для отображения выбранного текста и иконку стрелки `.csl74-icon-chevron-down`.
* Инициализирует `csl74Menu` на созданном контейнере.
* При выборе элемента меню автоматически синхронизирует значение с нативным `<select>` и вызывает событие `change`. Для получения или изменения значения из кода следует использовать стандартные методы jQuery: `$(select).val()` и `$(select).val(newValue).trigger('change')`.

### Настройки (`options`)
* `items` (Array|Function|Promise): Массив элементов (или функция/Promise, возвращающая его) для заполнения списка. Если передан, нативный `<select>` очищается и заполняется новыми тегами `<option>`. Если равен `null` (по умолчанию), элементы меню автоматически считываются из существующих `<option>` нативного селекта.
* `placeholder` (String): Текст, отображаемый в `.csl74-select-value`, если ни один элемент не выбран. По умолчанию `''`.
* `onSelect` (Function): Колбек при выборе пункта меню: `function(value, item, event)`.
* `onOpen` (Function): Колбек при открытии меню. По умолчанию добавляет класс `is-open` на контейнер `.csl74-select`.
* `onClose` (Function): Колбек при закрытии меню. По умолчанию удаляет класс `is-open` с контейнера `.csl74-select`.

## 5. Таб-контрол: `$.fn.csl74Tabs`

Компонент вкладок с автосборкой из существующей HTML-структуры и поддержкой динамического добавления вкладок.

### Сигнатура
```javascript
const tabs = $(selector).csl74Tabs(options);
```

### HTML-разметка
Дочерние элементы контейнера оборачиваются в панели, а заголовки и иконки переносятся в навигационную шапку:
```html
<div class="csl74-tabs">
  <div data-title="Основное" data-icon="csl74-icon-file">
    Контент первой вкладки
  </div>
  <div data-title="История" data-icon="csl74-icon-time">
    Контент второй вкладки
  </div>
</div>
```

### Настройки (`options`)
* `active` (Number): Индекс активной вкладки по умолчанию (`0`).
* `onSelect` (Function): Колбек при переключении: `function(index, tabData)`.

### Методы экземпляра
Плагин возвращает экземпляр `TabControl` (также сохраняется в `$(selector).data('csl74Tabs')`):
* `addTab(title, icon, activate)`: Создает и возвращает jQuery-объект новой панели (`$panel`), сохраняя цепочку вызовов (например, `.addTab('Новая').text('Контент')`). Если `activate === true` или это единственная вкладка, делает её активной.
* `selectTab(target)`: Переключает активную вкладку. Принимает индекс (число), jQuery-элемент панели/кнопки или объект данных вкладки.
* `getActiveTab()`: Возвращает объект активной вкладки (`{ title, icon, $navItem, $panel }`) или `null`.
* `getTab(index)`: Возвращает данные вкладки по её индексу.

## 6. Выбор даты и времени: `$.fn.csl74DatePicker`

Компонент выбора даты и времени (календарь) с поддержкой ручного ввода и вызова через кнопку-триггер.

### Сигнатура
```javascript
// Вызов на поле ввода
$(inputSelector).csl74DatePicker(options);

// Вызов на группе/контейнере (автоматический поиск инпута и кнопки внутри)
$(groupSelector).csl74DatePicker(options);
```

### Настройки (`options`)
* `trigger` (String|Boolean|jQuery): Элемент вызова календаря (кнопка). Может быть селектором (например, `'.speed-button'`), объектом jQuery или `true` (автопоиск соседней кнопки в контейнере). При наличии триггера клик работает в режиме переключения (toggle).
* `openOnInput` (Boolean): Открывать календарь при клике в `<input>`. По умолчанию `true`, если триггер не задан; если передан `trigger` или плагин инициализирован на контейнере группы, по умолчанию `false`, позволяя свободно редактировать значение вручную.
* `format` (String): Формат даты/времени (например, `'DD.MM.YYYY'` или `'DD.MM.YYYY HH:mm'`).
* `time` (Boolean): Отображение блока выбора времени.
* `onSelect` (Function): Колбек при выборе даты: `function(value, date, $input)`.
* `onOpen` (Function): Колбек при открытии календаря: `function($el, $input)`.
* `onClose` (Function): Колбек при закрытии календаря: `function($input)`.
