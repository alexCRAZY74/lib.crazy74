# crazy74.jquery — тренер-файл (jQuery-плагин)

Файл: `lib.crazy74.jquery.js`
Формат: IIFE `(window, $, crazy74)`. Если `window.jQuery` отсутствует — выходит сразу (`if (!$) return;`). ⚠️ `crazy74` захватывается как параметр **на момент подключения файла** — проверки на его отсутствие нет, поэтому `lib.crazy74.js` обязателен и должен грузиться раньше. Многие функции работают и без `crazy74` (есть fallback-ветки), но не все.

---

## $.getGUID()
`() → string` — просто `crazy74.uuid.get('v4')`. Требует core-библиотеку (без fallback).

## $.fn.SmartTime(dt, options = {})
Живое "умное" время на элементе(ах). `defaults = { interval: 10000, maxAgoSec: 86400 }`, мёржится через `crazy74.array.merge(true, ...)` если core доступен, иначе `Object.assign`.

Поведение:
- Если `dt` передан — сохраняется в `data('smartTimeRaw')` + `data('smartTimeOptions')`. Если не передан — читаются ранее сохранённые (повторный вызов на том же элементе без даты просто обновляет/перезапускает таймер с текущими настройками).
- Существующий интервал на элементе всегда сначала чистится (`clearInterval` + `removeData`), защита от дублей при повторных вызовах.
- `update()`:
  - С core: парсит дату через `crazy74.date.parseDate`; если не распарсилась — таймер останавливается.
    Если `diffSec < 0` (дата в будущем) **или** `diffSec >= maxAgoSec` — текст ставится через `fmtSmart` (статично, один раз) и таймер останавливается.
    Иначе — текст через `fmtAgo` (относительное время), обновляется каждые `interval` мс. `title`-атрибут всегда = `formatLocale`.
  - Без core (fallback): просто `toLocaleString()` нативной датой, без склонений/тултипов.
- Таймер (`setInterval`) стартует только если дата валидна и попадает в диапазон `[0, maxAgoSec)` — то есть только для "недавнего прошлого". Для будущих дат и дат старше `maxAgoSec` рендерится один раз и не обновляется.
- Данные хранятся в `.data()`: `smartTimeRaw`, `smartTimeOptions`, `smartTimeTimer`.

Использование: `$('.time').SmartTime(row.created_at)`, повторные вызовы безопасны (не плодят таймеры).

## $.maxZIndex / $.fn.maxZIndex(opt)
`defaults = { inc: 10, group: '*' }`.
1. Всегда сначала считает `zmax` — максимальный `z-index` среди элементов, найденных по `$(opt.group)` (по умолчанию — вообще все элементы страницы `'*'`). `NaN`/`'auto'` трактуются как `0`.
2. Если вызвано как **статичный** `$.maxZIndex(opt)` (`this.jquery` отсутствует) — просто возвращает найденный `zmax` (число), ничего не меняет.
3. Если вызвано как **метод коллекции** `$(selector).maxZIndex(opt)` — для каждого элемента коллекции по порядку: `zmax += opt.inc`, затем `css('z-index', zmax)`. То есть выставляет z-index каждому элементу выше текущего максимума, с шагом `inc`, сохраняя порядок коллекции (последний элемент коллекции получит самый большой z-index).

⚠️ Одна функция под двумя разными семантиками (get vs set) в зависимости от способа вызова — при генерации кода важно не перепутать `$.maxZIndex()` (только чтение) и `$('.modal').maxZIndex()` (чтение + запись).

## $.fn.exists()
`() → boolean` — `this.length > 0`. Не требует core.

## $.fn.destroy()
`() → jQuery` (chainable) — для каждого элемента: снимает все обработчики (`.off()`), затем `.removeData().empty().remove()`. Полная очистка + удаление из DOM. Не требует core.

## $.fn.outerHTML()
`() → string` — возвращает HTML-разметку самого элемента (включая его собственный тег), через `clone().wrap('<div>').parent().html()`. Не требует core. Работает только с первым элементом коллекции (jQuery `.html()` берёт первый).

## $.fn.FormData()
`() → Object` — сериализует форму (или набор полей) в plain-object на основе `.serializeArray()`.
- Одиночные поля → `object[name] = value || ''`.
- Повторяющиеся имена (чекбоксы-массивы, multi-select) → автоматически превращаются в массив при втором совпадении.
- Пустое значение поля → `''` (не `undefined`).

Аналог "получить данные формы как объект", похоже на `FormData` из vanilla JS, но возвращает обычный объект, а не `FormData`-инстанс.

## $.isEmpty(val)
`(val) → boolean`:
- `null`/`undefined` → `true`.
- строка/массив → `true` если `.length === 0`.
- объект (не массив, не строка) → `true` если `Object.keys(val).length === 0`.
- всё остальное (числа, включая `0`, `boolean`, включая `false`) → `false`.

⚠️ Отличается от `crazy74.array.notEmpty` из core-файла (там своя, другая трактовка "пустоты" — см. `crazy74_trainer.md`). Не смешивать эти две функции.

### Общие ловушки для генерации кода
1. `$.getGUID` и полноценный `SmartTime` требуют загруженный `crazy74` — без него будут ошибки (`getGUID`) или урезанный fallback (`SmartTime`).
2. `SmartTime`: повторный вызов на том же элементе без второго аргумента — это способ "обновить/перезапустить" тем же `dt`, а не поставить дату заново.
3. `maxZIndex` — двойное поведение (get/set) зависит от контекста вызова, не от аргументов.
4. `FormData()` (плагин) — не путать с нативным `FormData` API браузера; возвращает обычный `{}`.
