# Changelog

Все заметные изменения в проекте **`lib.crazy74`** и демонстрационном модуле будут документироваться в этом файле.

Формат основан на принципах [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/), и проект придерживается [семантического версионирования](https://semver.org/lang/ru/).

---

## [1.0.0] — 2026-08-19

### Добавлено
- **Базовое ядро PHP (`lib-php`)**:
  - Реализован единый автозагрузчик классов `SharedCommon::auto_load` и система инициализации `App::startup()`.
  - Добавлены служебные классы и хелперы: `array_var`, `request`, `lang`, `dates`, `number`, `session`, `utils`, `debug`, `console`, `errors`, `worktimes`, `SessionCache`.
  - Реализован модуль взаимодействия с LLM REST API (`AI/Request`, `AI/Response`, `AI/API`) с поддержкой интеграции Google Gemini и OpenAI-совместимых провайдеров (OpenRouter).
  - Интегрирован и адаптирован форк шаблонизатора Twig 1.15.1 для совместимости с современными версиями PHP.
  - Добавлена каскадная система загрузки и сборки JSON-словарей локализации (`language/`).
- **Клиентская библиотека JS (`lib-js`)**:
  - Создан ванильный модуль `lib.crazy74.js` для работы с DOM, датами, числами, генерацией UUID, массивами и локализацией на клиенте.
  - Разработан комплект jQuery-расширений и плагинов `lib.crazy74.jquery.js` (`SmartTime`, `maxZIndex`, `FormData`, `destroy`, `exists`).
- **Демонстрационное приложение (`demo`)**:
  - Создана архитектура на базе контроллеров страниц (`TwigPage`).
  - Реализован единый AJAX-диспетчер `App::ajax()` и точка входа `index.php`.
  - Добавлены демонстрационные сервисные классы `AIGemini`, `AIOpenRouter`, `App`, `db`.
  - Разработан набор Twig-шаблонов, инсетов, SCSS/CSS-стилей и демонстрационных страниц.
- **Документация**:
  - Созданы технические руководства `lib.crazy74.md`, `lib.crazy74.jquery.md`, `php-shared-lib.md`, `README.md` и `PROJECT.md`.

### Изменено / Рефакторинг
- Выполнен перевод базовых PHP-классов (`array_var`, `request`, `lang` и др.) на строгую типизацию `declare(strict_types=1)` с поддержкой PHP 8.2 и PHP 8.3.
- Унифицированы структуры локализационных JSON-словарей для синхронной работы серверного (`lib-php`) и клиентского (`lib-js`) слоев.
- Проведена адаптация шаблонизатора Twig к требованиям PHP 8.2+ (устранены предупреждения о депрекации устаревших конструкций).
